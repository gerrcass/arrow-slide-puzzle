# Domain docs

Single-context repo.

## Before exploring, read these

- `GLOSSARY.md` at the repo root.
- `docs/adr/` — read every ADR touching the area you are about to change. `ADR-0002` is a load-bearing invariant: removal is monotonic and the game has no dead ends.

Use the glossary's vocabulary in tickets, tests, UI copy, and code identifiers. If a needed concept is missing, note it for `/domain-modeling` rather than inventing a synonym.

If a change contradicts an ADR, surface it explicitly before proceeding.
