# 05: Nana Pearl — tutorial and contextual guide

**What to build:** An original elderly guide introduces the rule on first run, reacts to the first collision, a win, and running out of hearts, and never blocks the board. Her three-beat tutorial advances on real player actions and can be skipped or replayed.

**Blocked by:** 03.

**Status:** ready-for-agent

- [ ] Original inline-SVG Nana Pearl portrait with at least four expressions (neutral, warm, concerned, delighted) and a cream speech bubble.
- [ ] First run presents a skippable three-beat tutorial: tap a clear ribbon → watch it leave → hearts are for mistakes; beats advance on player actions.
- [ ] Contextual bubbles fire at most once each for first collision, first win, and first out-of-hearts; they are dismissible and non-blocking.
- [ ] Tips can be switched off; tutorial can be replayed; flags persist.
- [ ] Guide copy is brief, warm, and never scolds; it uses the glossary vocabulary.
- [ ] Guide state tests and a keyboard/screen-reader pass over the bubble and dismiss control pass.
